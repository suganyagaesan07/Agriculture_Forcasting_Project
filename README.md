# 🌾 AgriPulse Analytics – Agricultural Crop Yield & Demand Forecasting

### Power BI | Power Query | DAX | Data Analytics

## 📌 Project Overview

AgriPulse Analytics is an interactive Power BI project designed to analyse agricultural crop production, sales, demand, inventory and wastage across 10 districts in Tamil Nadu.

The project aims to transform raw agricultural data into meaningful business insights that can support procurement planning, inventory management and decision-making.

## 🎯 Business Objectives

- Analyse crop production and yield across different districts.
- Identify high-performing crops and regions.
- Compare crop production with market demand.
- Forecast demand for the next six months.
- Monitor warehouse inventory and wastage.
- Evaluate business scenarios using What-if analysis.

## 📂 Dataset Description

The project contains nine tables:

**Fact Tables**
1. Fact_Production
2. Fact_Sales
3. Fact_Demand
4. Fact_Inventory
5. Fact_Weather

**Dimension Tables**
1. Dim_Crop
2. Dim_Region
3. Dim_Warehouse
4. Dim_Date

**Geographical Coverage:** 10 districts in Tamil Nadu  
**Historical Data Period:** January 2022 – December 2025  
**Forecast Period:** January 2026 – June 2026

**Crops Analysed:** Paddy, Maize, Groundnut, Sugarcane, Cotton and Coconut.

> Note: The datasets used in this portfolio project are synthetic and created for analytical demonstration. They do not represent actual company transactions or official government statistics.

## 📐 Data Modelling

Implemented a Star Schema data model connecting five fact tables with four dimension tables.

Key dimensions include:
- Crop
- Region
- Warehouse
- Date

This structure supports consistent filtering and analysis across business processes.
